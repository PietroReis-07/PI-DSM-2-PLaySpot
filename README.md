# PI-DSM-2-PLaySpot
projeto integrador PlaySpot

## Estrutura do projeto

- `Frontend/`: arquivos HTML, CSS e recursos visuais do aplicativo.
- `Backend/`: estrutura reservada para API, rotas, controladores, modelos, serviços e banco de dados.
  - `src/routes/`: rotas da API.
  - `src/controllers/`: controladores das rotas.
  - `src/models/`: modelos e representação das entidades.
  - `src/services/`: regras de negócio.
  - `src/config/`: configurações do backend.
  - `database/`: scripts SQL do banco de dados.
